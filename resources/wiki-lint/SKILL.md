# Wiki Lint — 知识库语义体检

程序体检（断链、孤立页、证据失效）由 Meiqiu 自己做；这个 skill 做程序做不了的**语义**检查。

## 步骤

1. 读 vault 根的 CLAUDE.md（规范）和 wiki/index.md（页面清单）。
2. 通读全部页面（四类目录下的 .md）。页面多时可以只读 index 里摘要提示有重叠的组。
3. 按下面四类问题检查：
   - **矛盾**：两页对同一件事说法不一致。判断哪个更新/依据更高（human > code > inferred），建议：保留哪个、另一个标 deprecated 或补 contradicts 链接。
   - **被取代的旧说法**：同一主题在多页重复，或旧页内容已被新页覆盖。建议：旧页标 deprecated 并在新页 Evidence 加 supersedes。
   - **提到但没成页的概念**：正文反复出现某个项目/机制/人名却没有自己的页。建议：建新页，列出哪些页该链过去。
   - **缺交叉链接**：明显相关但 related 互不相链的页。建议：补 related。
4. 产出**建议清单**，格式：
   ```
   ## 体检建议（<日期>）
   1. [矛盾] 页 A 说 X，页 B 说 Y。建议：以 A 为准，B 标 deprecated。依据：A 是 human 级，B 是 inferred 级。
   2. [没成页] 「xxx」在 3 页出现但没有自己的页。建议：建 concept 页，从 A、B、C 链过去。
   ...
   ```
5. **不要直接改页面**。把建议清单给用户，等他逐条确认后再动手改。
